## UI Specifications
The UI must have a modern, minimalistic look-and-feel, and be as follows:
1. **Left-side panel:**
    Divided into Action Panel and Files List
    a. Action Panel:
        - Located on the upper section
        - The top-left corner has a gear icon that takes to the settings menu
        - To the right of the gear, there's a bar that shows the name of the current work directory. When clicked, it spawns a window from the OS so the user can select the current work directory.
        - Under the gear and the directory selector, there's a search bar. The user can input text to search for a file name.
    b. Files List:
        - Composed of lines, each one representing a file from the current work directory.
        - If the amount of shown files exceed the height limit of the panel, they can be scrolled down. 

2. **Raw-Text section:**
    By default, takes half the space remaining after the placement of the left-side panel. Is divided in header and body.
    a. Header:
        - Located at the top.
        - Shows the name of the current open file. If no file is open, just show "Untitled".
        - To the right of the file name there's a "Save" button.
    b. Body:
        - A simple multi-line text input field.
        - Located under the header.

3. **Processed-Text section:**
    Receives the text generated by the LLM. Is divided in header, body and prompt.
    a. Header:
        - Same as the header from the Raw-Text section, but to the left of the file name there's a "Toggle" button.
        - When clicked, the Toggle button will toggle between pure text and the rendered Markdown view.
    b. Body:
        - Either a multi-line text input field (like the Raw-Text section), or a rendered Markdown view, depending on the state of the Toggle button.
    c. Prompt:
        - Located under the body.
        - Contains a text input line to send the LLM additional information.
        - To the right of the text input line there's a "Send" button, shaped as a circle with a right-pointing arrow inside.

4. **Separation lines:**
    - Exists between the Left-side panel and the Raw-Text section ("Separator A"), and between the Raw-Text section and the Processed-Text section ("Separator B").
    - They can be dragged to change the width of the sections. When one grows, the other shrinks.
    - In the middle of the Separator B there's a circular button that sends the Raw text to the LLM and the processed text appears in the Processed-Text section.
